# Deck production materials

Working material for `../Planning-and-Task-Decomposition.pptx`. The deck itself
is the deliverable; nothing here is presented.

```
POWERPOINT-BRIEF.md   the slide-by-slide spec the deck was built from:
                      copy, layout, figure, presenter line, timing, alt text
assets/               original SVG figure sources (maroon / parchment /
                      charcoal / signal green; no logos, wordmarks or photos)
```

The deck was rebuilt from these as native PowerPoint shapes rather than imported
images, so every figure stays editable in PowerPoint. Edit the deck directly;
these files are the record of how it was specified, not a build input.
